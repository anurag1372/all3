Quick Setup & Credential Guide

Self-contained loopback configuration. Credentials stay private on your machine in .env.

1

1. Canvas LMS API Token

Generate a Personal Access Token:

  1. Direct link: https://canvas.eee.uci.edu/profile/settings ↗
  2. Scroll down to Approved Integrations and click + New Access Token.
  3. Add purpose All3 Integration and click Generate.
  4. Paste into .env as:
CANVAS_API_TOKEN=your_token_here
2

2. Ed Discussion API Token

Generate your discussion token:

  1. Direct link: https://edstem.org/us/settings/api-tokens ↗
  2. Click Create Token.
  3. Copy the token string and paste into .env:
EDSTEM_API_TOKEN=your_token_here
3

3. Gradescope Zero-Click Chrome Extension

No manual cookie copying required:

  1. Open Chrome and navigate to chrome://extensions/.
  2. Toggle on Developer mode in the top-right corner.
  3. Click Load unpacked in the top-left corner.
  4. Select the extension/ folder inside this repository.
  5. Visit gradescope.com once. The extension auto-detects your session and posts it to 127.0.0.1:3000. You can also click on Sync Now in the extension popup.
GRADESCOPE_COOKIE="auto_persisted"
4

4. Local Security Guarantees

This integration is bound exclusively to 127.0.0.1 loopback. Outside devices on your Wi-Fi network cannot connect to port 3000, and your course data / cache / outputs are strictly ignored in .gitignore.

✓ Local Loopback Security:
• Private tokens and cookies stored exclusively on local disk
• Zero remote telemetry or third-party cloud routing
• Bound to loopback address (inaccessible across LAN/Wi-Fi)
5

5. What Final .env Looks Like

File: .env at project root

Once all three platforms are configured, your completed .env file will look like this:

# Canvas LMS (Personal Access Token)
CANVAS_API_TOKEN=7~abcdef1234567890abcdef1234567890

# Ed Discussion (API Token from settings)
EDSTEM_API_TOKEN=ed_tok_abcdef1234567890abcdef123456

# Gradescope (Auto-populated by Chrome Extension or paste manual)
GRADESCOPE_COOKIE="signed_token=...; _gradescope_session=..."

# Local Server Loopback Port (Optional, defaults to 3000)
PORT=3000
